AZURE LOCAL CAPSTONE

Six machines. Practical cluster engineering.

The ambition was a six-node Azure Local POC, built from six available rack workstations. Bringing that design to life meant working through storage symmetry, network validation, hardware compatibility, and limited memory.

A deliberate four-node scope delivered the working POC. Explore how individual machines become pooled storage and managed compute, with Azure Arc, Kubernetes, useful workloads, and recorded recovery tests.
